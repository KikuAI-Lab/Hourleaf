# Hourleaf App Store screenshots

These screenshots are the reviewed source assets for the Hourleaf 1.0 App
Store listing. They were captured from Release builds with deterministic demo
data. They contain no personal ledger data, account details, or device
identifiers.

## iPhone 6.9-inch

Each localization contains three `1320 x 2868` PNG files in this order:

1. `01-quick-entry.png`
2. `02-history-calendar.png`
3. `03-monthly-report.png`

Directories: `en-US/iphone-6.9`, `ru/iphone-6.9`, and `uk/iphone-6.9`.

## Apple Watch 46 mm

Each localization contains one `416 x 496` PNG file:

1. `01-direct-entry.png`

Directories: `en-US/watch-46mm`, `ru/watch-46mm`, and `uk/watch-46mm`.

Apple Watch assets belong to the Apple Watch section of the same iOS App
Store record. They are not a separate App Store product.
