# Hourleaf 1.0.2 UX release notes

Class: immutable implementation history. Owner: Hourleaf Issue #3. Update only
until the 1.0.2 release outcome is recorded.

- Compact only the normal Dynamic Type Add layout. Accessibility sizes retain
  the original roomier controls and scrolling behavior.
- Keep the existing App Shortcuts capability, but remove its technical setup
  UI from Settings. Two plain guide links replace it.
- Russian app installations open the Russian guide. Other app languages open
  the English guide because the requested public guide languages are RU/EN.
- App Store submission remains gated on signed archive, upload, processing,
  version attachment, and provider readback.
